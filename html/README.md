# Kaboot promotional page

This is a standalone static site. Open `index.html` in a browser to preview it;
no build, dependencies or running quiz server are required.

`index.bak` preserves the original product-focused page. It uses the same
stylesheet as the current page.

To publish with GitHub Pages, copy `index.html` and `styles.css` into a separate
public repository, then enable Pages in that repository's settings using the
branch and root folder. The website and its source will be public. Do not copy
quiz data, answers or private files into the promotional repository.
